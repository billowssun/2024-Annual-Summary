# 2024 年度总结入口汇总

汇集多个 App 的 2024 年度报告入口，方便集中访问年度回顾。

## 内容与结构

`index.html` 汇集视频、音乐、阅读、社交等平台的年度报告入口；`icons/` 保存平台图标。此仓库汇总跳转入口，不读取或保存用户的个人年度数据。

## 预览与发布

直接用浏览器打开 `index.html`，无需安装依赖或构建。也可在项目目录运行：

```bash
python3 -m http.server 8000
```

访问 `http://localhost:8000`。仓库包含 GitHub Pages 静态发布工作流。

## 维护

修改 `index.html` 中的平台、文案和跳转链接即可。年度活动可能已结束或需要对应 App 登录；这些链接不保证持续有效。
